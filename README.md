# Chess Play vs Computer App

Вэб-приложение для игры в шахматы с компьютером (движок Stockfish).
Проект состоит из двух частей: Java/Spring Boot бэкенд и React/Vite фронтенд.

## Особенности
- **Игра против Stockfish**: выберите уровень сложности (ELO) и сторону (Белые, Черные, Случайно).
- **Настройка внешнего вида**: возможность менять тему доски и стиль фигур.
- **Анализ партий**: после завершения игры (или если вы сдались) можно запустить анализ. Для каждого хода Stockfish покажет свою оценку (в сантипешках), лучший ход, а также вы получите текстовое объяснение качества вашего хода.

## Требования
Для локального запуска вам понадобятся:
- **Java 21**
- **Node.js** (версия 18+)
- **Stockfish**: Движок должен быть установлен в системе (по умолчанию ожидается по пути `/usr/games/stockfish`). В Ubuntu/Debian можно установить с помощью `sudo apt-get install stockfish`.

## Структура проекта
- `/backend`: Серверная часть на Java, Spring Boot, Gradle. Предоставляет WebSocket (и REST) API для общения с движком Stockfish по протоколу UCI.
- `/frontend`: Клиентская часть на React, TypeScript, Vite. Стилизация выполнена с помощью Tailwind CSS. Используются библиотеки `react-chessboard` и `chess.js`.

## Инструкция по запуску

### 1. Запуск Бэкенда (Spring Boot)
Перейдите в директорию `backend` и запустите приложение с помощью Gradle:

```bash
cd backend
./gradlew bootRun
```
Бэкенд запустится на порту `8080`.

### 2. Запуск Фронтенда (React/Vite)
Перейдите в директорию `frontend`, установите зависимости и запустите сервер для разработки:

```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на порту `5173`. Откройте в браузере `http://localhost:5173`.

## Дополнительно
Приложение разработано таким образом, что для игры не требуется регистрация. Наслаждайтесь классическими шахматами!
